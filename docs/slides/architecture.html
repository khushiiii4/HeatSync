ThermoGrid: a closed control loop for a simulated data center

Services sense rack heat, predict hotspots 60 s ahead, move workloads away and tune cooling. Each decision changes the next reading.

The simulated plant

  • 4 cooling zones, 16 racks (4 x 4)
  • 2 s tick, 60 s forecast horizon
  • WATCH 30, WARNING 34, CRITICAL 38 C
  • About 36 demo workloads

Design choices

  • Each service owns its data; others use REST or events
  • Services fail independently, the rest keep working
  • Dashboard polls, so each panel fails alone
  • Security only at the gateway, plus an internal token

Evidence so far

  • 549 automated tests, 0 failures
  • Failure scenarios: 3 clean runs of 59 checks
  • k6: 0.00 % errors, p95 21 ms (local Docker)
All hardware is simulated; no machine learning. Runs in Docker on one computer.ThermoGrid, Phase 13
